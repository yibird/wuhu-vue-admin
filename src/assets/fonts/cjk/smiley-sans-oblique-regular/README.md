适用于浏览器的多片段快速加载的中文字库
- 这是我以oooooohmygosh身份发布的第一款字体，11月15日正式开源发布，大家可以免费商用无任何限制，也可以修改创作。说个不太切实际的梦想，我希望以这个身份发布的所有作品，都是开源或者公益的。 这套字经过我和其他字体设计师伙伴们一年多的波折，终于要面世了。这款字虽然是美术字，但却是一个有挑战的命题。因为它有三个特征「大弧线、窄、斜」，每一项都很难做好。更何况把它们仨融合到了一起，还要去追求稳、匀、整……
- 参见:  https://www.maoken.com/freefonts/17247.html
- 更多字体: WEB在线中文字体搜集:  https://github.com/wc-ex/cn-fontsource

### 使用
- CDN 直接调用
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/cn-fontsource-smiley-sans-oblique-regular/font.css"></link>
  <style>
    html{
      font-family: Roboto, "Smiley Sans Oblique", sans-serif;
    }
  </style>
  ```
- 本地化
  > npm i cn-fontsource-smiley-sans-oblique-regular

  > 加载: font.css
