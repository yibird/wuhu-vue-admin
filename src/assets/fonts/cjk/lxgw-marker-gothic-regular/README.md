适用于浏览器的多片段快速加载的中文字库
- 本字体是基于 たぬゴ角 改造的具有马克笔书写风格的中文字体，可用于漫画、广告等用途
- 参见:  https://github.com/lxgw/LxgwMarkerGothic

### 使用
- CDN 直接调用
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/cn-fontsource-lxgw-marker-gothic-regular/font.css"></link>
  <style>
    html{
      font-family: Roboto, "LXGW Marker Gothic", sans-serif;
    }
  </style>
  ```
- 本地化
  > npm i cn-fontsource-lxgw-marker-gothic-regular

  > 加载: font.css
